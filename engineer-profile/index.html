Engineer Profile

Kevin Hertlein

Embedded Software Engineer

Building the software that brings hardware to life.

I specialize in low-level platform software, hardware enablement, and device driver development across microcontrollers, application processors, heterogeneous SoCs, and FPGA-based systems.

My work centers on software closest to the hardware: board support package development, platform integration, hardware bring-up, and robust interfaces that help teams move faster.

In RF environments, software quality directly influences measurement accuracy, calibration quality, and system performance. That work shaped a disciplined engineering approach focused on repeatability, evidence-driven debugging, and strong lab validation.

I enjoy integration problems that cross boundaries: reading schematics and datasheets, probing behavior with oscilloscopes and logic analyzers, and translating hardware capabilities into maintainable software.

Core Expertise

  • Embedded platform software and hardware enablement
  • Device driver development
  • Board support packages and platform integration
  • Hardware bring-up and root-cause analysis
  • Embedded RF systems and instrumentation
  • FPGA-based embedded systems
  • Heterogeneous processor architectures
  • Embedded Linux
  • Performance optimization and characterization
  • Hardware and software co-design
  • Cross-platform debugging

Engineering Philosophy

I build embedded platforms other engineers can trust: maintainable, extensible systems designed from first principles and ready for future products.
