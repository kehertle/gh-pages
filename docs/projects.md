# Projects

A selection of embedded and systems projects.

## ESP32 Baby Event Tracker

- Repository: [github.com/kehertle/esp32-baby-event-tracker](https://github.com/kehertle/esp32-baby-event-tracker)
- Embedded event tracking system on ESP32 and MicroPython for feeding, sleep, and caregiver events.
- Designed for daily use.

## RPMsg IIO DesignKit

- Repository: [github.com/kehertle/rpmsg_iio_designkit](https://github.com/kehertle/rpmsg_iio_designkit)
- Linux and Zephyr co-design reference for heterogeneous systems.
- Uses RPMsg and OpenAMP

## TinyStreamer (Experimental)

- Repository: [github.com/kehertle/tinystreamer](https://github.com/kehertle/tinystreamer)
- Lightweight streaming and media pipeline exploration under embedded and RTOS constraints.
- Investigates porting high-level GStreamer concepts into lower-level real-time environments.
